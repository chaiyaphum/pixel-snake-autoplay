# Changelog

Changes to the reusable package are recorded here. Test and deployment results belong in release evidence rather than being inferred from this list.

## Unreleased

### Added

- A dependency-free browser controller with explicit installation, start, stop, status, and destruction lifecycle.
- A 21 × 21 cycle planner with an interchangeable excluded cell and target-aware shortcut reserve.
- Canvas-based game observations and ordinary keyboard movement through the existing game.
- Normal 110 ms timing by default and optional local acceleration.
- A standalone browser bundle and a Node.js development workflow.
- Documentation of compatibility, privacy, cleanup, verification, and contribution boundaries.
